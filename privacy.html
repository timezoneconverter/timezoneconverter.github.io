Privacy Policy

This site does not run accounts and does not ask you to sign in. The tools process your input in your own browser, on your own device. No input you type into a tool is sent to a server by us, stored by us, or shared by us. We do not use the tools to collect names, addresses or payment details. Pages may be served through GitHub Pages, which may keep standard server logs for security and delivery, as described in the hosting provider's own privacy notice. We do not set advertising cookies and we do not run third-party trackers on these pages. If you email us, we use your message only to reply to you. You can clear any browser data for this site at any time from your browser settings.

Every page follows the same approach: plain language, a worked example, and a result you can check yourself. If a page does not answer your question, the guides section lists twenty related articles, and the tools section lists the four tools for this topic. Start with the main tool on the home page, then read the guide that matches your exact task.
